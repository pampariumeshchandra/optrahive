# OptraHive

Static marketing site for OptraHive (HRMS). Deployed to GitHub Pages via `.github/workflows/static.yml`.

## Structure
- `index.html` - single page site
- `css/styles.css`, `js/main.js`
- `assets/images/brand` - logo and favicons
- `assets/images/team` - team photos
- `assets/images/clients/hyundai-glovis` - launch event photos (our biggest client)
